# 소품샵 협동 시뮬레이터 — 플레이어 설명서

시작 씬은 `Assets/PickAndPlaceShop/Scenes/PickAndPlaceShop_MainStreetSlice_Multiplayer.unity`입니다. 호스트가 하루 진행, 손님, 유행, 주문, 자동 뽑기와 공용 컨테이너를 판정하고 클라이언트는 결과를 동기화받습니다.

## 핵심 루프

하루는 총 8분입니다.

- 준비 2분: 오늘의 유행과 목표가 공개됩니다. 진열과 수동 뽑기를 할 수 있습니다.
- 영업 5분: 손님을 응대하고 계산하면서 진열을 보충합니다. 뽑기도 가능하지만 계산대가 비면 대기 만족도가 내려갑니다.
- 마감 1분: 진행 중 결제와 뽑기 라운드를 끝낸 뒤 매출·판매 수·목표 결과를 정산합니다. 자동 장치는 마감 중 멈춥니다.

## 뽑기

- 캡슐 희귀도는 기계에 생성될 때 확정됩니다. 흰색 무지(일반), 파랑 실선(고급), 보라 이중선·광택(희귀), 금색 이중선·별(초희귀)로 색과 표식을 함께 확인할 수 있습니다.
- 실제 상품은 캡슐을 획득한 뒤 같은 희귀도 상품 풀에서 공개됩니다. 캡슐 색과 내용물 등급은 바뀌지 않습니다.
- WASD는 카메라를 돌려도 항상 기계 기준 방향입니다. 집게 아래 위치 표식으로 낙하 지점을 확인합니다.
- 기본 기계는 한 번에 하나만 획득하고 추가 경품은 플레이필드로 돌려보냅니다. 프리미엄 기계는 동시에 들어온 경품을 모두 획득합니다.
- 수동 획득은 개인 가방을 먼저 사용하고, 가득 차면 공용 창고로 이동합니다.

## 상품·컬렉션

- 같은 상품은 슬롯당 기본 10개까지 합쳐집니다. 빈 슬롯이 없어도 기존 스택에 여유가 있으면 획득할 수 있습니다.
- 컬렉션은 등록 데이터에서 런타임 집계하며 총 200종입니다: 동물 50, 우주 40, 레트로 40, 계절 30, 기타 40.
- 등급 조건의 `희귀상품 N개`는 서로 다른 종류 수가 아니라 중복을 포함한 누적 획득 개수입니다.
- 지명 가제는 옛 문구점, 벚꽃길, 강변 상가, 수집가의 거리이며 데이터의 `provisionalName` 표시로 나중에 일괄 교체할 수 있습니다.

## 판매와 손님

손님은 입장 → 진열 탐색 → 상품 선택 → 계산 대기 → 결제 → 퇴장 순서로 행동합니다. 진열이 비어 있으면 새 손님이 생성되지 않습니다.

- 손님은 저장되는 30명 고유 풀에서 방문하며 각자 선호 카테고리와 마지막 만족도를 가집니다.
- 만족도는 계산 대기시간을 가장 크게, 진열 다양성을 중간, 희귀 진열을 작게 반영합니다. 만족도가 평판 획득에 반영됩니다.
- 같은 손님이 3회 구매하면 단골입니다. 단골은 더 자주 재방문하고 구매 금액이 오르며 선호 상품을 추가 구매할 수 있습니다.
- 매일 한 카테고리가 유행합니다. 판매가가 15% 오르고 해당 취향 손님의 방문과 만족도에 보너스가 붙습니다. 유행은 준비 알림과 Tab 가게 현황에서 확인합니다.

## 온라인 주문

포장대는 가게 확장 Lv2와 평판 10에서 열립니다. 게시판 주문의 상품과 수량을 창고 또는 진열대에서 꺼내 포장·발송하면 일반 판매보다 높은 대금과 평판을 받습니다. 기한은 실시간이 아니라 게임 내 일 수로 계산됩니다. 실패 시 평판이 소폭 감소하지만 이미 열린 지역·시설·등급은 다시 잠기지 않습니다. Lv5 온라인 주문실은 동시 주문 상한을 2건에서 5건으로 확장합니다.

## 자동 뽑기 장치

평판 40부터 기계마다 장치 한 개를 구매할 수 있습니다. 기계 앞에서 R을 눌러 관리 화면을 열고 켜기/끄기, 수집함 비우기를 선택합니다.

- 기본 60초마다 정상 플레이 비용을 공용 자금에서 차감하고 판정표로 한 번 시도합니다. 화면 밖에서 물리를 돌리지 않습니다.
- 성공률은 수동 평균의 0.5배입니다. 자동 획득은 집게 숙련도와 기본 일일 뽑기 목표에 포함되지 않습니다.
- 자동 획득은 장치 수집함 10칸 → 공용 창고 순서로 들어갑니다. 둘 다 차면 장치가 멈추며 상품은 사라지지 않습니다.
- 수동 조작이 시작되면 자동 장치는 일시 정지하고, 조작이 끝나면 다시 동작합니다.
- **최고 등급인 초희귀 상품은 직접 뽑아야 합니다.** 자동 장치에서는 나오지 않습니다.

## 조작

- WASD: 플레이어 이동 / 뽑기 기계 기준 집게 이동
- 마우스: 시점
- E: 상호작용
- Space: 집게 투하
- Tab: 가게 현황·목표·단골·유행·자동화 요약
- R: 가까운 자동 뽑기 장치 관리
- Esc: 메뉴 또는 조작 종료

## 저장·네트워크 규칙

저장 버전 4에는 하루 구간·잔여 시간·유행·일일 목표, 손님별 구매와 만족도, 온라인 주문과 남은 일수, 자동 장치 설치·가동·수집함, 기계 안 캡슐 희귀도가 포함됩니다. 알 수 없는 저장 버전은 안전한 기본값으로 복구합니다. 호스트만 하루 전환, 손님, 만족도·평판, 주문, 자동 시도와 비용을 계산하므로 인원수만큼 비용이 중복 차감되지 않습니다.
