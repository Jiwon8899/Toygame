# 미야옹 츄르 부자가 될 거야

고양이 굿즈를 뽑고 진열해 판매하는 소품샵 시뮬레이터입니다. 시작 씬은
`Assets/PickAndPlaceShop/Scenes/PickAndPlaceShop_MainStreetSlice_Multiplayer.unity`입니다.

## 하루 진행

하루는 준비 2분, 영업 5분, 마감 1분으로 구성됩니다. 준비가 시작되면 오늘의 유행과
목표가 공개되고, 영업 중에는 손님 응대와 계산, 진열 보충, 뽑기를 함께 진행합니다.
마감에서는 매출, 판매 건수, 목표 달성 여부를 정산합니다.

## 손님과 리뷰

손님은 입장 후 진열대를 탐색하고 원하는 상품이 있으면 계산대로 이동해 구매하며,
상품이 없으면 빈손으로 퇴장합니다. 행동 분기는 아래 두 신호만 사용합니다.

- 구매했는가
- 선호 상품이 진열되어 있었는가

예전의 만족도 점수, 대기시간·진열 가중치, 단골 전환, 고정 손님 선호도와 재방문
보너스는 사용하지 않습니다. 마감 리뷰 별점은 그날의 판매량과 일일 목표 달성률로만
계산하며, 임계값은 `ShopDifferentiationConfig` 데이터에서 조정합니다.

## 상품 진열과 단축 슬롯

상품을 자유 좌표에 놓거나 군집·대칭·희귀도·밀도로 평가하는 큐레이션 시스템은
사용하지 않습니다. 진열 상품은 씬에 보존된 `DisplayPrize_0`부터
`DisplayPrize_7`까지의 고정 슬롯에 순서대로 배치됩니다.

- 상품 보관함에서 개인 상품을 클릭하면 손에 듭니다.
- 개인 상품에 마우스를 올리고 Shift+1~5를 누르면 단축 슬롯에 등록합니다.
- 1~5를 누르면 해당 상품을 손에 들고, F를 누르면 취소합니다.
- 진열대 앞에서 E를 누르면 고정된 빈 슬롯에 진열합니다.

상품을 진열한 뒤에는 개인 인벤토리에서 실제 수량이 차감되며 단축 슬롯도 즉시
갱신됩니다. 큐레이션 점수, 등급, 코디네이터, 전용 사진 모드는 표시되지 않습니다.

## 뽑기와 상품 보관

캡슐 희귀도는 스폰 시 결정되고 실제 상품은 획득 후 같은 희귀도 풀에서 공개됩니다.
수동 획득은 개인 가방을 우선 사용하고, 가방이 가득 차면 공동 창고로 이동합니다.
같은 상품은 한 칸에 최대 10개까지 쌓입니다.

## 온라인 주문과 유행 뉴스

온라인 주문 게시판과 주문 아이콘은 실제 주문 데이터의 상품, 수량, 남은 기한을
표시합니다. 유행 뉴스는 준비 구간마다 오늘의 유행 카테고리와 함께 갱신됩니다.
두 UI는 장식용 화면이 아니라 호스트가 관리하는 실제 게임 상태를 읽습니다.

## 기본 조작

- WASD: 플레이어 또는 뽑기 장치 이동
- 마우스: 시점
- E: 상호작용 및 고정 슬롯 진열
- Space: 뽑기 투하
- 1~5: 상품 단축 슬롯 선택
- Shift+1~5: 가리킨 개인 상품을 단축 슬롯에 등록
- F: 들고 있는 상품 취소
- Tab: 가게 현황과 상품 관리
- Esc: 메뉴 또는 조작 종료

## 저장 및 권한

호스트만 하루 전환, 손님 행동, 주문, 자동 뽑기와 비용을 확정하고 공유 컨테이너
변경을 직렬화합니다. 저장 데이터에는 하루 상태, 목표, 주문, 상품 컨테이너, 해금과
단축 슬롯이 포함됩니다. 제거된 만족도·단골·큐레이션 데이터는 저장하거나 복원하지
않으며, 저장 버전 16에서 안전한 기본값으로 이전됩니다.
